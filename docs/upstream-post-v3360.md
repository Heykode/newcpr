## 数据合同与差异

- 0078 仅调整数据库初始化策略。运行时缺失 JSON 字段仍采用旧兼容缺省，
  避免已保存的旧配置在升级时隐式开启排队；新建库写入完整的新排队值。
  本地仍是 sticky/fallback 队列结构，不宣称整个调度器与官方逐字相同。
  新库不能仅凭 revision=1 判断：0063 会自动提升版本。沿用 migrate_schema 在迁移锁内
  设置的 cpr.fresh_install 标记，不扩大旧库升级条件。
- 0079 增加 model_requests/ops_events 套餐快照。历史记录不回填当前套餐；
  诊断的名称、认证类型和套餐来自同一条最新请求，缺失事实不会借用更早请求补齐。
  用量列表和错误列表同样读取快照，不影响 token、金额或请求结果。
- 0080 将名称存储边界由 128 字符改为 512 UTF-8 字节；既有合法名称均兼容。
  不新增第二个可编辑名称，不修改凭据、设备身份、出口或重登保留行为。
- 旧迁移保持冻结。新增字段/约束须按迁移感知发布流程处理；本轮不部署。
