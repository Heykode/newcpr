| --- | --- | --- |

## 必要结构映射

上游地区对齐 helper 直接采用固定官方源码。账号的代理绑定/地区规则、
代理优先级和延后注入位置按官方实现。前端地区规范化及校验 helper
采用官方实现，仅将类型 import 改为本仓库对应模块。

保留本仓库现有 `openaiLocationOverrideEnabled`、`openaiRequestLocation`
存储字段及 API 路径，不迁移为官方数据库列名。在构建配置快照时将开关
折叠成可选全局地区，再传入既有路由和 attempt context。旧数据全局地区
为 null 且开关开启时，采用官方 RequestLocation 默认值，不使用 UA 启动配置。

原生代理自动地区检测继续提供代理的有效地区值；其检测、修订号及失败保留
机制没有重写。未复制官方插件或其他无关模块。地区覆盖不配置真实出口 IP，
不修改 UA、TLS、账号调度策略或会话身份算法。
