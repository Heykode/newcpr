## 实施边界

用户批准原生账号名称、导入、表单校验、统计空态及组件交互对齐。
名称沿用 `customName`，保留账号身份、2FA、导入模板、监测模板、出口与 Excel 合同。
不移植 Link、上游 API Key、插件工作台、隐私策略、批量编辑改版和官方发布编号。
不修改请求路由、重试预算、UA、计费；测试仅在 OVH 隔离环境执行，不部署。

本地并未依赖 `@codex-proxy/ui`，不能以更改不存在的依赖版本代替实现。
逐项记录与官方差异，不将未适用的插件主题桥称为已合并。

## 原生适配核对

| 项目 | 处理与差异 |
| --- | --- |
| Form 校验 | 移植 UI v0.8.0 Form/FormItem 与验证器、异步结果失效、字段登记/定位；本地 Base 组件接入。无 model 的布局容器继承外层表单，避免嵌套 form 和校验断链。错误文字保留文档流，防止遮挡现有紧凑布局。 |
| 原生设置 | 账号、分组、普通代理、设置、位置、模型映射接入字段校验；代理测试只验证连接字段。既有后端范围、MiB/秒换算、Excel 安全检查继续生效，不借此修改调度参数。 |
| 名称 | OpenAI OAuth 首次允许空名称；自定义展示名仍由 customName 承载，单账号导入才覆盖。后台拆分任务与 2FA 入池也遵守此规则；xAI 保留原有 OAuth 初始名称兼容行为。 |
| 旧账号迁移 | 不执行官方清理原始 name 的迁移：本项目已有独立 custom_name，原始 name 属于既有身份合同，不覆盖已有名称、邮箱和凭据。 |
| 统计 | 概览刷新保留上次数据，当前失败清空、过期失败不覆盖；无数据显示零值，空健康时间线保持 96 格布局。缺失的图表样本仍保留 null。 |
| UI 交互 | 表格展开动画、弹出层 transition、checkbox 防误选文字、Markdown alert 与消毒保留。 |
| 主题 | 使用独立变量映射，保留原生 cp CSS 和已保存配置；输入框与次级按钮透明色校验/编辑对齐适用能力。不强制把所有 CSS 改为 z，不引入插件主题传输桥或无调用方的公共 API 别名。 |
| 不适用 | 官方 DatePicker 本项目没有对应组件；侧栏主/子菜单联动的变更属于插件菜单，当前没有该入口。上游 API Key 累计用量与 Link 导入发现/并发 4 刷新按既定排除项不加入。 |

所有新增验证使用合成凭据或隔离数据库，未登录真实账号、未修改生产配置。
