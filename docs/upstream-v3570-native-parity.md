# v3.57.0 合并记录（进行中）

| 范围 | 本地接入和验证边界 |
| --- | --- |
| Chat | 公共协议层增加直接转换、工具、结构化输出及 usage。固定样例中的 67 项 Chat 测试通过。HTTP 入口保留原始 Chat 参与路由，Codex 和 xAI 选号后直接转换，原生 Messages 不再由 Codex OAuth 执行。API 到 Provider 的完整交付、旧回归和严格模式还需验收。新的 Codex Chat 路径使用正常额度资格。 |
| Antigravity | 原生 GenAI 和 Chat、系统指令合并、计数、传输和点数接入。保留本地额度观测比较写回。Provider 隔离测试在接入菜单之前通过 110 项。旧版本的提示词用例先失败，接入后通过。管理端余额和开关尚待实际浏览器验证。 |
| GenAI 鉴权和菜单 | HTTP 鉴权断言通过 2 项，验证 Google 请求头作用域、Authorization 优先级及原始载荷。目录断言通过 4 项，包含原始名称和菜单名、授权范围、同页顺序、详情及翻页。Codex 客户端菜单还需按真实调用方验收。 |
| Codex 压缩 | 按请求保留 HTTP 或 WS。两项契约测试分别覆盖 HTTP 压缩以及显式 WS、WS 入站、续接和普通轮次。旧本地 OAuth 凭据没有官方的账号级传输编辑字段，参见 v3.55.2 差异账。 |

| 在线连接池 | 官方 `pool/mod.rs` 和 `pool/lease.rs` 将许可绑定到一次建连，所有账号共享的默认上限为 8。NewCPR 采用相同的许可生命周期，按账号的有效并发值分别限制同时建连数。复用、输出、空闲和关闭保留各自的连接归属，出口代理继续限制实际连接数。普通请求仍由原账号调度控制。隔离主机上的四连接回归在旧实现先失败，修改后通过，覆盖成功、失败、取消及原会话复用。最终源码通过 287 项传输库测试、587 项传输集成测试和 1 项普通账号并发调度测试。其他在线设置另行验收。 |
| 其他 | 数据库历史套餐、OpenAI 请求和连接池设置、旧配置升级、界面及全量路径核对仍在进行。尚未通过全工作区测试、真实数据库迁移、浏览器或生产验收。 |
