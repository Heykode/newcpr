## 提交后复查

| 问题 | 归因、影响与处理 |

| Chat 的显式账号亲和丢失 | 新 HTTP 入口手工复制头部时漏掉调度提示，Codex Chat 选号又固定传空亲和。两层均已用失败回归确认。入口改用既有 `session_context`；选号前从原始 Chat 读取显式会话或可信提示，使用原账号绑定命名空间与当前调度模式，观测与实际选号一致。仍在选号后做目标协议转换，不建立原生续接所有权。 |
| xAI 旧会话解析失败 | 新 `response_stored` 字段缺少兼容默认值；固定官方目标同样没有默认值。旧持久记录会在出站前报协议错误。旧记录默认 false，沿用历史重放，不猜测上游保存成功；新记录显式值和非法类型校验保留。隔离回归先失败后通过，不能据此宣称完整上游续接已验收。 |
| Google 鉴权头结构化导出未脱敏 | 原移植仅更新纯文本正则，JSON 字段、二元组和 name/value 头部仍漏掉 `x-goog-api-key`。新增真实导出入口回归先失败；补充结构化敏感字段后通过，保留业务错误正文。 |
| 测试结构接入遗漏 | API 的固定源码清单缺少 `genai/agent_menu.rs`；WS 两个测试适配方法写进生产 impl，违反已有结构检查。补齐实际清单，将适配方法移入既有私有测试模块，没有放宽 WS 结构检查。新增 xAI 私有会话测试登记精确 owner。两项结构检查已通过。 |
