- CI 暴露 Host 生命周期旧夹具的活动任务清单漏了 `RequestAnalytics`；补齐测试计划，并将它加入“缺少必需任务拒绝启动”的既有回归。生产 bootstrap 已注册该 Worker，未删除或放宽 Host 必需任务校验；Host worker/lifecycle 20 项通过。
- 原始写日志后立即读完整统计的夹具改为明确执行后台投影；账号窗口和分页的即时
  源差量合同仍单独保留。不在生产读路径增加同步回填来迁就旧测试。
- 摘要改用官方窄指标；Provider/吞吐/缓存分布由洞察接口验证。官方直方图允许的
  3% 分位数误差与 `percentilesApproximate` 配套验证；计数、Token 和费用仍要求精确。

  备份和本地日志分类的必要覆盖。一次性移植脚本、性能测量脚本和原始日志不提交。
