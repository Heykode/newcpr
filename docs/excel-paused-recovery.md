# Excel 暂停账号恢复探测

## 使用

在账号编辑的 Excel 设置中，开启“暂停后自动探测 Excel，成功后恢复调度”，设置探测间隔后保存。默认关闭；默认间隔 60 分钟，范围 1–10080 分钟。账号导入、批量编辑、账号模板和重登推送的新账号设置复用同一配置。

如需 403 后自动暂停并在恢复后重新启用，将“Excel 遇到 HTTP 403”设为“暂停账号调度”。若选择“关闭 Excel 模式”，账号已经离开 Excel 模式，不会启动本功能。手动暂停也会被此开关自动恢复；需要长期停用时，先关闭恢复探测。

批量编辑必须勾选“应用 Excel 恢复探测更改”。旧模板未包含此配置时保留账号原值，不会隐式关闭。普通账号编辑未修改恢复设置时不会提交这一字段。

## 运行逻辑

1. 保存配置或暂停后，从配置的下一次间隔开始检查；后台每 60 秒扫描，排队可能推迟开始，不是保存立即发请求。
2. 只检查仍处于 Excel 模式、调度已暂停、凭据有效的 OpenAI OAuth 账号。不解除独立质量规则拥有的暂停。
3. 选择最近触发自动 403 暂停的模型；没有这项记录时，选择当前有效 Excel 列表第一个模型。原失败模型被移出列表时记录 `model_unavailable`，不另选模型来制造成功。
4. 固定这个账号和模型，使用实际 BPS 链路发送随机回声请求，专用请求指定 `reasoning.effort=low`、`stream=true`、`store=false`。沿用原凭据、指纹、UA、代理和 IPv6 策略，不回退原生 Codex、不换账号；探测不占业务并发，仍遵守账号请求间隔。
5. 必须 HTTP 200，完整读完响应，且仅出现一次 `response.completed`、最终状态为 `completed`。最终输出可忽略 `reasoning`，其余只能是 assistant 的 `output_text`，合并去除首尾空白后必须精确匹配随机回声。工具、图片、拒绝、错误角色、重复完成、后续失败/坏 JSON、网络断流、空回复均不能恢复。返回“非403”不代表成功。
6. 全局最多三个探测；请求期限 45 秒，取消后等待执行器排空再释放槽位。两分钟租约用于进程异常退出后的回收。失败按照配置间隔重试。
7. 重新暂停、改配置、换凭据、删除账号、关 Excel 或关恢复开关，会使旧探测结果失效。提交恢复时再次校验，不能被晚到结果覆盖。其他账号正常恢复只发布配置版本，不会使并行探测互相作废。

恢复只修改调度状态和当前自动暂停标记，不清除凭据/额度保护，也不改分组或原生质量检测。正常业务请求继续使用 CPR 原调度规则。

## 状态与审计

账号编辑中可查看最近探测结果、时间、模型与下一次计划。完整探测恢复后，Excel 头像可回绿色；历史 403 时间仍在悬浮说明中。之后再次暂停会清除“已验证恢复”标记，手动启用不能冒充新的验证成功。

探测使用既有 `account_quality_check` 内部请求落账，实际成本保留，不计入业务并发和客户端请求统计。专用状态只保存固定结果码，不保存随机回复正文或凭据。成功恢复产生 `account.excel_recovery` 管理审计。

一次探测成功只能证明当时该账号、模型和链路可用，不保证所有 Excel 模型、图片/工具请求或后续请求都不再发生 403。

## 参考对齐范围

对照 Sub2API `production@9f7d96be367e795bd76e1f45c82bd5d4c563e0fa`（2026-09-30，v2.9.6 发布准备）的 `openai_excel_bps_recovery.go` 与 `account_test_service_bps_probe.go`：补齐恢复探针的 `low` 档位、完整最终输出和 nonce 检查。与其限制一致，探针总响应上限 2 MiB、SSE 单行上限 1 MiB；完整读取仍受原有 45 秒期限和取消控制约束。

严格验证位于 OpenAI provider 的原始响应层，在普通 Excel 事件转换之前执行。触发标记与预期 nonce 仅能由可信内部恢复入口设置，不能从客户端 JSON 开启，也不序列化到上游配置字段。正常 Excel 请求不会增加全流缓冲；普通连接测试、原生 Codex 与原生质量检测的默认档位保持不变。

这不是整体 1:1 替换：手动暂停恢复、优先探测原 403 模型、CPR 指纹/UA/出口及持久化竞态保护，仍保留用户已批准的 CPR 实现。不移植参考项目另一个独立的三轮工具测试。

## 持久化和停用

- 迁移 `0058_excel_paused_recovery.sql` 创建独立配置和租约表，冻结迁移不可修改。
- 账号删除级联删除配置；占用中的全局槽位保留至取消排空或租约过期，不能提前挤入第四个请求。
- 停用只需关闭账号开关，不影响普通 Codex、原生质量检测、账号模板其他字段或业务出口。
- 若整体移除 Excel，按 `excel-removal.md` 移除本功能 worker、配置/UI 和可信 probe 标记。数据库历史迁移保留；旧版本若不认识模板 JSON 中的新键，降级前需要处理模板兼容性，不能宣称二进制直接回滚。

## 验证边界

本次使用隔离 PostgreSQL、合成 provider/worker 和浏览器 API fixtures 验证；没有调用生产账号、部署或改生产配置。真实上游恢复可用性由部署后每个账号的探测结果决定。
