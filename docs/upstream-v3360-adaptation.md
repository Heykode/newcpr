## 必要适配

- WS 使用本地 `PumpSocket.send`，对应官方 `inner.stream.send`，经过同一底层流。
  保留 socket 销毁后释放物理容量、代理许可和取消所有权的现有合同。
  新增 Ping 写超时同时接入退出原因、日志详情、指标及流错误投影。
  已输出后超时继续使用现有 PostSendAmbiguous 边界，不打开重复连接；对应回归在
  官方“持续 Pong 仍按业务超时结束”的断言之外保留这一检查。
  本地“运行时外构造连接池后首次请求启动维护”用例也按官方 GC 用例回应 Ping，
  继续断言原最大连接年龄内回收，不再假定维护期间第一帧一定是 Close。
- ETag 保留 NewCPR 已有刷新中取消能力；失败处理与官方一致交回监管器，
  不在任务内部吞错。既有 Host 负责 1、2、4、8、16、32、60 秒有界退避及健康恢复。
- 前端使用原生 Base 组件，覆盖官方的更新时间、帮助说明和 Escape 先关闭说明行为。
  保留导入模板的已知目录分页、手动模型输入、异步取消及已选模型，不虚构聚合目录时间。
  `modelLimitations` 文案仍供本地账号模板摘要使用，模型目录字段新增官方名称。
- API 测试复用本地 AccountDirectoryItem 夹具与管理员会话 cookie，校验内容与官方相同：
  查询/刷新两入口、存在/缺失时间、部署时区输出、模型 ID 列表。
  时间格式化使用现有 deployment_timezone / timezone_rfc3339 / timezone_datetime，
  对应官方 TimePresenter 的相同输出；不引入第二套全局时区状态。
- 官方 API Key 专属表单的 SSE 标签调整排除；不接入插件、PRISM 或上游 API Key 账号。
