# 详细错误采集

入口位于使用统计的请求明细，紧邻错误排查。开关为全局设置，不要求预选
账号或创建任务。默认关闭；既有定向采集的 enabled 配置不会自动启用全局
模式，必须明确开启 globalErrors。

## 采集与查看

- 齿轮设置文件总容量（MiB，默认 1024）、保留天数（默认 7，范围 1-30）
  和是否保存媒体正文（默认关闭）。
- 使用统计及错误列表接口不携带采集正文，也不预取正文。打开请求详情后，
  按当前 Request ID 查询关联记录，正文每次最多读取 256 KiB。
- 切换请求、关联记录或关闭详情会清空旧正文并取消未完成读取。正文不会写入
  浏览器持久存储或混入安全诊断包；详细材料导出是独立、显式的管理员操作。
- 仅在观察到错误后保存材料。中途失败、最终恢复的请求仍可保留排障证据；
  没有错误的成功请求不落盘。不自动重放请求。
- 关闭开关停止新增采集，已保存的记录仍可读取。全局模式按每条记录完成时间
  清理；历史定向任务继续使用原有清理规则。全局开关明确开启后，重启会恢复
  全局采集；旧定向任务仍标记为中断，不自动恢复。
- 同一请求可能包含多次尝试，上游材料保留各自的尝试编号。未发送上游时没有
  上游正文，不能据此认定选中账号已被调用。
- 保留既有内存、片段和正文大小预算。超限材料可能不完整；默认达到磁盘配额
  会停采，也可选择下述循环覆盖方案。采集故障不能替换业务响应或触发上游重试。
- 普通对话和工具内容仍可能含敏感信息。认证字段和媒体策略沿用已有脱敏逻辑，
  管理员必须谨慎处理材料。未采集的历史正文不能事后补回。

## 使用

打开“使用日志 → 请求明细/错误排查”旁的详细错误采集设置。

- **满了停止采集**：默认方案，与旧版本一致。空间不足时保留已有材料并暂停采集。
- **循环覆盖最旧材料**：空间不足时按保存时间从旧到新删除材料，继续保存新错误。
- **清理采集材料**：确认后分批删除本实例在本次操作截止时间前已经落盘的材料。
  清理期间产生的新材料保留；可以停止后续批次，已完成的删除不可恢复。

设置中显示已保存材料的条数和逻辑字节数。清理不保存尚未提交的设置草稿，也不修改
采集开关。已启用的全局采集如果此前因容量暂停，完整清理后有空间且存储正常时恢复。
已关闭的采集不会被开启，旧的按账号/分组/Key 限时任务不会被复活。

## 删除边界

只处理本实例数据库索引关联的 UUID 采集文件及对应采集记录。请求/响应正文、媒体正文
如果包含在这些文件中，会一起删除；使用明细、普通错误摘要、诊断 trace、金额、账号、
凭据、调度、配置以及其他实例和目录文件不删除。删除任务仅接受确认和截止时间，
不接受目录、路径、实例或数据库表名；符号链接和异常文件类型拒绝处理。

清理需要管理员认证并记录管理审计，每批最多 256 条。多批使用同一个服务端截止时间，
不会随着新请求不断扩大删除范围。网络失败可能发生在部分材料已删除之后，界面会提示
结果未确认，不会自动重试或显示全部成功。保留天数仍由原有日志清理机制管理。

## 容量行为

覆盖模式先将新材料完整写入一个有界、尚未入索引的文件，确认单条能够容纳后才淘汰
最旧材料。单条超过总配额或既有 128 MiB 单条上限时，仅跳过该条，不删除旧材料，
后续错误仍可采集。真实磁盘/数据库故障仍会停采，不会影响正常请求转发。

配额沿用原有已保存文件逻辑字节计算，不等于文件系统分配块数。完整新文件发布前
最多临时多占一条材料的空间，上限为总配额与 128 MiB 中的较小值；磁盘应预留余量。
已经打开的下载句柄可以完成，文件删除后的实际磁盘回收可能等待这些句柄关闭。

## 兼容

原定向采集路由保留用于兼容历史记录，不再出现在侧边栏。配置读取和按请求检索接口
复用现有管理员鉴权、实例隔离和正文访问审计。数据库迁移 0054 仅为按请求检索增加
索引，不改业务请求、调度或账号表。

`quotaPolicy` 保存于原有配置 JSON，缺失时为 `stop`，不修改历史迁移。旧版严格反序列化
程序不认识此字段，回退前需核对并处理配置兼容性，不能只替换旧二进制。
