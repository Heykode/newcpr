# 详细错误采集

入口位于使用统计的请求明细，紧邻错误排查。开关为全局设置，不要求预选
账号或创建任务。默认关闭；既有定向采集的 enabled 配置不会自动启用全局
模式，必须明确开启 globalErrors。

- 齿轮设置文件总容量（MiB，默认 1024）、保留天数（默认 7，范围 1-30）
  和是否保存媒体正文（默认关闭）。
- 使用统计及错误列表接口不携带采集正文，也不预取正文。打开请求详情后，
  按当前 Request ID 查询关联记录，正文每次最多读取 256 KiB。
- 切换请求、关联记录或关闭详情会清空旧正文并取消未完成读取。正文不会写入
  浏览器持久存储或混入安全诊断包；详细材料导出是独立、显式的管理员操作。
- 仅在观察到错误后保存材料。中途失败、最终恢复的请求仍可保留排障证据；
  没有错误的成功请求不落盘。不自动重放请求。
- 关闭开关停止新增采集，已保存的记录仍可读取。全局模式按每条记录完成时间
  清理；历史定向任务继续使用原有清理规则。全局开关明确开启后，重启会恢复
  全局采集；旧定向任务仍标记为中断，不自动恢复。
- 同一请求可能包含多次尝试，上游材料保留各自的尝试编号。未发送上游时没有
  上游正文，不能据此认定选中账号已被调用。
- 保留既有内存、片段、正文大小和磁盘预算。超限材料可能不完整；达到磁盘配额
  会停采，调整容量并重新保存可恢复。采集故障不能替换业务响应或触发上游重试。
- 普通对话和工具内容仍可能含敏感信息。认证字段和媒体策略沿用已有脱敏逻辑，
  管理员必须谨慎处理材料。未采集的历史正文不能事后补回。

原定向采集路由保留用于兼容历史记录，不再出现在侧边栏。新版新增独立、
有界的配置读取和按请求检索接口，复用现有管理员鉴权、实例隔离和正文访问审计。
数据库迁移 0054 仅为按请求检索增加索引，不改业务请求、调度或账号表。
