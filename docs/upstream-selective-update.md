# 官方功能选择性适配

本批按现有 CPR 的传输、身份、调度及 State 合同适配，不整套覆盖官方实现。
参考官方提交固定为 `9b58649090f112e575e1abbc668d3aaebe7c8ae1`，
UA 样本辅助参考 PR #272 的固定提交。

| 功能 | 本次效果 | 保留的边界 |
| --- | --- | --- |
| WS 退出诊断 | 分清真实关闭、读流结束及本地保活超时 | 不增加重试，不改连接和压缩参数 |
| 账号保存 | 提交配置不再等待远端模型目录；慢目录刷新可被配置提交让开 | 账号权限、实时并发限制仍及时发布 |
| 原生模型目录导出 | 从指定账号导出其实际目录，保留模型原生字段 | 只读，不借用其他账号，不改变默认模型 |
| 返回模型显示 | 账号测试展示上游实际返回的模型名 | 没返回就空缺，不把请求模型冒充返回模型 |
| Key × 模型统计 | 独立分页，显示次数、Token 和费用缺失状态 | 不改计费事实、成功谓词或结算 |
| 分组用量归属 | 按实际服务账号当前所属分组计算，列表与监控一致 | 多组账号可计入多个组，不可把分组相加当总费用 |
| 外来请求头 | 增补过滤 `x-authenticateresponse` | 保留业务头及现有 UA、设备、会话头 |
| 自动出口地区 | 每代理选择开启，手填值独立保留，明确失败及双栈冲突 | 默认关闭；无推理时查询、无周期探测 |
| UA 辅助 | 识别 `codex_exec`，可把固定样本填入原自定义框 | 样本不自动保存、不自动跟随第三方更新 |
| 损坏候选 | 未固定、未发送时跳过本地损坏凭据 | 不修改账号健康，不改变精确续接或固定账号要求 |

自动出口地区详见 `proxy-auto-location.md`，用量归属详见
`usage-analytics.md`。

## 依赖范围

- `http` 从 1.4.0 更新至 1.5.0：包含 URI 校验边界、HeaderMap 内存安全相关修复
  和解析实现改进。采用原锁文件的精确更新，不全量重解依赖。
- `ipnet` 从 2.12.0 更新至 2.12.2：修复地址空间上界处网段生成、聚合的越界包含。
- 其他依赖版本不变，包括 OpenSSL、native-tls、rustls、reqwest、
  HTTP/2 与 WebSocket 实现；不借此更换握手、ALPN 或 TCP 策略。

## 不纳入本批

不新增定时预热、主动识别模型探针、插件、每账号或每 Key 的 UA 体系。
不加入 API Key 图片能力声明，不替换自定义 UA 自动更新来源，不修改 State
采集、Cookie 归属、额度权威、容量冻结或智能粘性评分。

本批包含新迁移 `0038_proxy_auto_location.sql`。部署前须使用与该迁移匹配的
审核和备份流程；不能把普通镜像切换当作无迁移发布，也不自动回滚数据库。
管理操作不再等待远端目录，不等于承诺推理首字延迟整体下降。
