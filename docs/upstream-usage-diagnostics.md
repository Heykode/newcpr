## 统计契约

- 诊断请求占比的分母来自相同时间、筛选和诊断维度范围下的全部匹配请求，在 Top 100 和 Key × 模型分页之前计算。
- SQL 只对维度汇总行计算分母，多币种费用行不重复计数。
- `retryCount` 仍是所有额外尝试的次数之和；`retryRate` 是发生至少一次重试的请求数除以请求总数。一个请求重试五次不会算成五个重试请求。
- 当前套餐通过内部账号 ID 关联，不能按邮箱混合个人与团队工作区。
- 套餐是当前状态，不是请求发生时的套餐快照；已删除账号或未知套餐不显示徽标。
- 套餐展示只使用已有 Provider 显示名称规则，不发起上游配额刷新，不参与调度。
