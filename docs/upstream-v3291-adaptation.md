## 不适用项

- `zip` 的官方升级用于 Windows MSIX 中提取 Desktop 与 bundled Core 版本。本项目
  没有 `zip` crate，也没有该 Windows 解析入口；当前 macOS 制品使用有界 HTTP Range
  及 `flate2` 读取，CLI 使用发布元数据。它与账号导入和模型请求压缩无关，不新增闲置依赖。
- 不引入插件、插件迁移、PRISM、请求隐私过滤、上游 API Key 账号或独立下游 Key 用量页。
- 不移植本项目没有使用的官方安装器，也不重排官方迁移编号。

## 运行边界

新增迁移 `0074_auto_reset_inventory.sql` 和 `0075_proxy_websocket_capacity.sql`，
不改已冻结的历史迁移。旧配置缺字段时保持到期用卡关闭、周额度不限、代理 WS 不限。
回退时的配置兼容注意事项见 `backend/migrations/README.md`。

代理预算作用于本项目 Responses WS 连接池及非池化 Responses 连接；不扩展到 Live
sideband，也不是跨进程配额。普通空闲连接沿本地创建时间排序回收，未改变账号池的
既有回收策略。调小上限不强杀在途连接，新请求根据自身冻结配置等待。

到期计划跨进程重启保存在数据库；结果未知的兑换仍由既有台账阻止重复使用，需按
原来的同幂等键恢复流程确认。本次不增加后台自动重试未知兑换，也不将重置卡当作
Codex 付费点数使用。

## 验证方式

最终验收仅在 OVH 隔离容器执行，使用合成上游、独立 PostgreSQL/Redis 和完全拦截
业务 API 的浏览器场景。本机仅编辑源码和查看验收材料，未连接或部署 16 核生产服务器。
验证结果另记于当前任务的验收记录；未使用真实账号消耗额度，未重新采样 TLS 指纹，
不以测试通过保证上游不会报错或账号风控降低。
