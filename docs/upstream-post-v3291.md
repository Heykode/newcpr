## 数据与生命周期

- 错误摘要只读取 `model_requests` 的最终错误字段，不从中间重试事件推断最终失败。
- 失败和未完成请求显示聚焦详情，仍可查看原有完整详情和诊断包；旧记录缺少尝试字段时正常展示。
- 并发接口仍为原有分页读取；前端每批最多 100 条，以首批总数确定本轮页数，按 `leaseId` 去重。
- 读取不申请、释放或调整租约。账号、并发池切换，关闭弹窗或页面不可见时取消读取；过期响应不能写回。
- 分页期间租约增删可能使本轮快照暂时缺项，下一轮刷新纠正；不把界面条数用于调度决策。

## 发布合同

- 构建保持并行，只有最终发布使用仓库级队列；候选镜像使用 SHA 标签。
- 镜像检查、签名和 Release 草稿附件完成后，才公开版本镜像与 Release。
- 稳定版同时比对当前 Release 和镜像的版本。旧版本和预发布不会覆盖 `latest`。
- 镜像与 GitHub 无法跨服务原子更新；每侧版本检查和摘要验证支持失败重跑，并阻止旧版回退。
- actionlint 1.7.7 尚不识别 `concurrency.queue`。按官方对这一条诊断精确忽略，并由发布测试约束值为 `max`，其他诊断仍阻断。
