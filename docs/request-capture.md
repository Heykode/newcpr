# 错误请求采集

参考 Sub2API v2.8.13 的 #77 和后续 #82，适配 CPR 原有请求上下文和
HTTP/SSE/WS 交付流程。默认关闭，不改变调度、粘性、凭据、出口、重试和计量。
这不是自动重放工具，不会代替用户重复请求上游。

## 控制

管理员在“请求采集”设置总开关、磁盘配额和保留天数，选择账号、API Key 或
分组以及采集时长。目标搜索复用管理端已有列表，不读取明文 Key 或账号凭据。

- 默认磁盘配额 1024 MiB、任务结束后保留 7 天；保留期可设 1 至 30 天。
  手动停止、关闭、容量停采和重启中断均从实际结束时间开始计算。
- 每个任务 1 至 1440 分钟，最多 16 个运行任务。
- 成功请求仅在内存中暂存，结束后丢弃，既不保存正文文件，也不建立错误索引。
- HTTP 错误、真实 attempt 失败、未完成终态和明确 WS 写入错误才保留。
  重试曾失败但最终成功的请求也保留。预算不足本身不算业务失败。
- Canonical completed 后的本地取消不被误认成上游失败；
  上游已完成后的真实交付故障仍可记录，不能用完成状态掩盖实际错误。
- 每个 WS 轮次独立拥有采集上下文，结束后释放，不串到下一轮。
- 关闭、停止或到期不再接收对应任务的新正文；已确认错误的部分记录可以收尾，
  标为不完整。重叠任务分别执行停止时刻和媒体策略。
- 重启将未结束任务标为中断，不自动续采；启动清理没有已提交索引的孤立文件。

## 内容与导出

正文分为客户端输入、实际选定账号的上游请求、上游响应和下游输出，保留 attempt
及 exchange 编号。账号任务不保留其他重试账号的上游正文，但可能包含该请求的
公共输入和最终输出。分组范围以请求认证后的 Key 分组快照为准。

结构化认证字段和请求头在写盘前移除；URL 整段脱敏，包括签名、路径和认证信息。
默认媒体字符串仅保留指纹；明确开启媒体选项后可以保留 JSON 中的内联媒体。
不会主动下载外部 URL。二进制、无法解析或超限的正文省略并标记不完整。
普通对话和工具字符串仍可能含敏感信息，不能把脱敏当成全内容安全保证。

管理 API 全部需要管理员认证，创建、停止、删除、配置、读取和导出进入管理审计。
正文只按文本显示，单页最多 256 KiB，不渲染 HTML。支持单条记录和停止后的整个
任务流式导出为 JSONL；任务导出含任务/实例和记录元数据，不在内存聚合整个包。
导出为调用时已收尾的记录快照，停止后尚在执行的错误请求应等待收尾再导出。
页面显示最近 100 个任务、200 条错误记录，Request ID 筛选针对该可见记录集；
整任务导出不受该列表条数限制。关闭功能后不允许读取/导出正文。

正文目录位于运行数据目录的 `request-captures`，目录权限 0700、文件 0600。
PostgreSQL 只存设置、任务和记录元数据；正文不写入普通日志或审计。
删除任务会删除对应文件；已经下载、备份或快照的副本不在自动删除范围内。

## 资源与失败隔离

| 项目 | 限制 |
| --- | --- |
| 并发采集会话 | 256 |
| 原始片段预留预算 | 64 MiB |
| 单记录片段 / attempt 摘要 | 512 / 256 |
| 单组 JSON 或 SSE 解析正文 | 8 MiB |
| 单条最终文件 | 128 MiB |
| 等待写入的已收尾错误记录 | 32 |
| 并发导出 | 2 |

64 MiB 是原始片段预留预算，不是进程内存上限；异步过滤只逐组解析、逐行写入，
JSON 解析、序列化、数据库和导出仍使用额外内存。实际可保留大小受共享预算限制，
不承诺每条长流都完整。采集不等待磁盘和慢消费者；不足时截断或跳过。

配额耗尽停止采集任务，不删除已有记录来腾空间。磁盘或文件锁故障仅停用此模块，
管理端显示存储异常，不阻止 CPR 正常启动或接收业务请求。修好目录后重启再新建任务。
已停止请求持有的内存直到请求收尾才释放，仍受共享上限约束。

本版是单实例本地存储，不支持跨节点共享正文目录或配置热同步。备份需同时保存
数据库元数据和正文目录；历史备份不会自动移除其中的采集数据。

## 适配边界

CPR 使用认证 Key 而非对方的用户体系；导出为 JSONL 而非 tar.gz。
采集从 Core 请求上下文建立后开始，不覆盖此前的认证、请求解码或准入拒绝。
WS 新轮次按当时运行任务匹配；开启任务不追溯已经开始的请求或轮次。
普通诊断仍使用原有安全摘要，不需要为本功能打开旧的原始报文转储。

回归位于 Store 请求采集测试、API 管理鉴权和真实 HTTP/WS 路由测试，
浏览器回归为 `frontend/tests/browser/request-capture.mjs`。测试使用合成数据；
通过合成测试不能称为对任何上游真实错误都已完成验收。
