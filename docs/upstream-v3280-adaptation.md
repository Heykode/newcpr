## 迁移与部署边界

只新增 `0073_group_image_generation.sql`，历史迁移不变。使用生产迁移入口或
`migrate_schema` 执行首次安装，可在同一 PostgreSQL 迁移锁内识别新库；直接调用
原始 SQLx 迁移器没有首次安装标记时，保守保留已有值。新建库初始化不会使用
配置版本号推测管理员是否保存过设置。

旧二进制不会执行分组生图权限，不能视为禁用分组的等价回退。
本轮未改部署流程、生产数据、账号身份、UA、HTTP/WS 出口、Excel 路由或账号切换剥离。
插件、PRISM、请求隐私规则和上游 API Key 账号功能仍排除。

## 验证与限制

后端使用合成上游响应、本机独立 PostgreSQL/Redis 验证；Web 使用完全拦截 API 的
Playwright 场景验证桌面和手机。重点覆盖元数据后 503 与回放屏障、失败标记隔离和
原子删除、生图权限与图片输入、保留旧配置、状态分页与质量检测隔离、诊断脱敏和下载。
