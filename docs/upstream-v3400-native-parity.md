## 有意保留的架构适配

- 默认大包阈值对齐官方 15.5 MiB，恢复阈值为 13.5 MiB。显式自定义值使用相同 2 MiB 回差；0 继续表示关闭主动大小分流。已有数据库中的显式值不被升级覆盖。
- 大小判断仍在账号身份投影、透支注入及 WS 序列化之后，以实际最终帧字节数为准。精确续接不偷偷改成 HTTP 新链，预热/增量成功不代表完整历史已能装入 WS。
- 重连建议是连接内临时信息，不序列化入持久会话。只有成功 response.completed 与当前 response ID 一致，终态写成功且当前没有已接收的排队消息，才发正常关闭帧。
- 本地保留独立 Store 与 Admin 类型，诊断字段经过两次投影，不只修改 API DTO。
- 本地保存错误详情的字段是 `raw_upstream_error`，不是官方的 `error_details`；查询映射和真实数据库回归必须使用本地字段。前端已有独立的客户端/上游传输列，保留这项等效展示。
- xAI 本次保留现有原生套餐来源，不引入官方另一套订阅端点或插件账户；修复范围是刷新保留资料、快照及日统计。
