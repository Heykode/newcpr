## 架构适配与边界

- 安装 ID 的 UUID 校验、空值、大小写归一及继承语义按官方实现。全局 UA 配置
  不允许 `installationId` 或 `inherit`，错误分类也对齐。每次请求采用当前全局 UA，
  不把保存 Key 时的 UA 永久固定。账号自身数据库身份不被覆盖。
- 本地原来没有官方完整 Key 画像预览界面及对应接口；本次接入安装 ID 编辑、生成、
  保存、清空及完整运行链路，没有另建完整画像预览页面。完整画像数据经现有 Key
  管理接口保存时会校验，编辑安装 ID 不丢弃其他画像字段。
- WS 池键、哈希和路由所有权都纳入有效安装 ID，修改 ID 后不能借用旧身份的连接。
  正常继承账号身份时默认行为不变。目录与 Live 不遗漏 Key 画像。
- 独立搜索、压缩、图片等 raw JSON 入口原本重建账号身份，仍显式清除 turn-state
  别名；不能因普通完整请求保留未知票据而改变这些独立接口的身份边界。
- 入口诊断使用本地 `RequestCaptureFactory`。关闭采集时快速退出；转储只观察调用方
  已消费的数据帧，不为了日志主动排空正文。未消费完明确标记不完整；已经进入模型
  执行的请求由原执行采集记录，不产生第二份失败材料。质量探测不进入数据面入口。
- 本地模型统计使用直接 SQL，没有复制官方插件 analytics bucket；两种查询入口使用
  同一健康公式。只有失败记录的模型也可以出现，最后成功使用时间允许为空。
- 官方代理批量分配上限 1000、画像大小及 UUID 等校验照搬官方约束，没有新增请求
  限速或缩小功能范围。原有代理修订冲突处理和账号身份、出口合同继续生效。
- 构建保留本地按包验证、Redis ACL、镜像证明、签名、安全扫描及已验证镜像部署；
  依赖、工具链、Dockerfile、build.rs 变化仍走源码镜像构建。缺少成功 CI 证据就完整
  重跑，不把失败或跳过视为通过。生产 IPv6 禁用策略和部署脚本未改动。
- 插件导入、中间件及无本地调用者的配置提示不硬搬；不恢复 PRISM、上游 API Key
  账号、隐私规则或已取消页面。官方版本号不直接覆盖 NewCPR 的发布版本。
