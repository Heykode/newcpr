# NewCPR 上游适配核对

适用于官方 CPR 与 NewCPR 的差异评估、代码移植及对应文档更新。
先执行项目 Trellis 流程，读取受影响层的合同；本技能不替代用户授权或项目边界。

1. 记录本地 remote、分支、HEAD 及官方起止提交。以源码行为对照，提交标题仅作线索。
2. 逐项标明原样移植、原生适配、已有等效实现和排除原因；不因提交包含插件就漏掉可独立迁入的原生修复。
3. 账号身份、出口、会话、租约、工具映射和费用结算遵循本地已有 owner。不要引入第二套调度或重复反馈。
4. 配置同时核对默认值、已有数据库值、旧客户端省略字段及显式关闭。不要将关闭功能等同于支持旧二进制降级。
5. 结果必须有相应证据：编译、单元、真实数据库、回环传输、页面交互各自说明覆盖范围。模拟不能证明上游线上行为。
6. 协议或设置改变时同步 API、部署示例及 Trellis 合同，就地更新现行行为说明；变更经过仅写在适配或发布记录。
7. 最终复查排除项、未提交文件和敏感信息；发布、标签、部署遵守当前用户授权。

该核对流程吸收官方 CPR `0f214c3e` 文档指南中的源码核实、关联说明同步和内容验收要求。
不依赖官方插件 SDK、CodeGraph 或官方发布脚本。
