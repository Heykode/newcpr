- QX 兼容模式按可信下游 Key、账号设备身份和原始会话/线程标记派生上游编号。
- 最终缓存键按线程编号统一，内部调度仍使用原始锚点，避免投影后的编号反向污染调度。
- WS 连接池加入下游 Key 隔离，并覆盖新建、恢复、owner 查找和 tombstone 路径。
- 换账号、换 Key、换线程时不会复用不属于当前调用方的连接或状态。
- 新轮次会同步清理内部字段、透传头和已知正文/元数据中的旧 turn state。
- 缺少明确编号时，字符串输入、用户消息和等价文本块使用统一回退规则。

### 调度与容量

- 增加账号满载时的有界等待，保留现有权重、智能粘性和账号选择方向。
- 等待受请求总截止时间、取消信号和实时账号资格约束。
- Redis 协调状态、账号并发上限、容量变化和连接回收增加联动保护。

### 接口、存储与验证

- 新增独立出站配置 API、预览、持久化和管理页面控件。
- 新增数据库迁移 `0011`、`0012`，旧迁移不改写。
- 补齐独立图片、搜索、压缩接口的账号身份隔离。
- 增加 HTTP/WS、TLS、UA、会话、连接池、跨账号和跨 Key 回归测试。

## 升级说明
