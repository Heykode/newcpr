# 管理安全与预算

## 运行设置保存冲突

- 对齐官方 `12771aca`：GET 和保存成功响应携带 `configRevision`；POST 必须带读取时的版本。
- API、Admin command、Store adapter 将该版本传到 `ControlPlaneReplacement.expected_revision`；
  PostgreSQL 在配置行 `FOR UPDATE` 锁内比较，过期返回冲突，设置与审计均不得写入。
- 复用全局 revision，不新建设置版本字段；其他推进全局版本的管理变更同样使旧表单过期。
- 409 保留前端草稿和原版本，不自动重新加载或用新版本静默重发。旧客户端缺字段必须重载升级。
- 保留 targeted mutations、可选字段继承、请求快照和账号身份合同；无需数据库迁移。
- 验证真实数据库的同版本并发单赢家、过期无写入、审计失败回滚及其他配置写入使旧表单过期。

- 管理密码通过现有 Admin AuthService 修改，不引入客户端 Key 登录或第二套后台鉴权。
- 改密验证现有会话、当前密码与新密码强度；尝试额度按管理员聚合在 Redis 中原子计数。
- PostgreSQL 原密码哈希 CAS 和审计写入必须同事务提交。Redis 会话仅保存加盐哈希的摘要；
  校验时与 PostgreSQL 当前值比较，不能依赖删除 Redis 记录完成撤销。
- 旧版无摘要会话失效后要求重新登录。上游账号 Cookie、凭据和会话画像不是该摘要的输入。
- 预算重置在 ClientKey owner 内实施，与窗口开启和结算共享 Key 行锁；普通准入只读，不推进配置 revision。
- 仅重置选择的 daily/weekly 窗口，并推进有效窗口的计费起点，保留结束时间与历史账本。
- 晚到费用按请求完成时间计入所选窗口；重复结算仍依赖请求 ID 幂等。
- 新增或调整这两个功能时覆盖审计失败回滚、并发 CAS、旧会话撤销、延迟结算及未使用 Key。

## 管理会话续期

- `POST /api/admin/auth/refresh` 延长闲置期限但不得超过登录时固定的绝对期限；
  `GET /api/admin/auth/status` 只读，不续期。首次导航用 status；页面活动不触发续期。
  业务鉴权失败或首次 status 返回未认证时触发单飞 refresh，恢复期间的新请求和迟到的旧 401 都等待当前续期。
  访问凭据到期但刷新凭据有效时允许轮换；刷新期限或绝对期限到期、改密撤销后必须重新登录，不添加轮询。
- Redis 续期比较完整预期记录并原子更新，不能覆盖并发续期的新期限或复活已删除会话。
  指纹仍按目标 Base64 SHA256 合同校验 PostgreSQL 当前密码，改密限速不变。
- 有有效指纹但无绝对期限的旧会话可用至原到期时间，不延长。无指纹会话仍须重新登录。
- 前端单飞续期与登录/退出串行化，失效操作不能丢弃仍在途的 Cookie 写入屏障；
  旧请求结果不能改变新会话。网络不可用仍保留三态恢复语义，不当作明确退出。
- 新登录使用独立 a2/r2 凭据，Redis 只保存摘要及派生盐，保留至刷新期限；访问期限为闲置期限四分之一且最多 24 小时。
- 刷新 Cookie 仅发往 `/api/admin/auth`；刷新凭据不能用于业务鉴权，逻辑会话 ID 本身不能用于鉴权或退出。
- 轮换通过完整记录 CAS，上一代刷新凭据在 30 秒内重试返回同一代凭据，超过窗口则原子撤销；CAS 不得重建已删除键。

## 预算结算幂等

- 新费用事件插入成功后才推进预算窗口；请求 ID 重复不得触发窗口推进或重置。
- 完成时间早于窗口起点的晚到费用，不推进该窗口；现有 reset 起点、费用账本与行锁保持权威。

## 异步预算结算

- 请求完成只登记费用，受监督的 Store writer 按同一 Key 小批次幂等落库；失败、超时或取消保留费用并重试。
- 准入在同一数据库语句快照中合并已落库与本进程待结算费用，剔除已提交请求 ID，不能重复扣费或绕过额度。
- 队列积压阻止新准入，但必须接收已准入请求的最终费用；不能丢弃这些费用或让响应等待数据库行锁。
- 保留原 Asia/Shanghai 日/周窗口、人工重置和请求完成时间语义；此队列不替代账号累计消费账本。
- 队列是单进程内存缓冲，不是持久消息队列。正常停机有界排空；进程被强杀时未落库费用仍可能丢失，不得宣称零丢失或跨副本共享待结算额度。
- 覆盖真实 PostgreSQL 慢写、写失败自动重试、取消后重排、队列满、重复登记与人工重置，不得将缺少数据库时的跳过作为通过。
